# Data

Datasets behind [oscarleo.com](https://oscarleo.com) and the
[newsletter](https://oscarleo.substack.com), published so others can check and
reuse them.

## Topics

Each topic is a folder with its own README that explains sources, methods and
caveats.

| topic | what |
|---|---|
| [topics/cbi](topics/cbi) | Citizenship and residence by investment worldwide: programmes, prices and rules over time, applications, approvals, money raised, buyers by nationality and a timeline. Every number with its source, page, quote and status |
| [topics/whistleblowing](topics/whistleblowing) | Whistleblower reward programmes: awards, cases and the rules behind them, sourced the same way |

## Other files

- `china_solar_makers_quarterly-revenue-and-profit.csv`: quarterly revenue and
  profit of Chinese solar manufacturers, used in an earlier chart.
