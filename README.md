# Data

Datasets behind [oscarleo.com](https://oscarleo.com) and the
[newsletter](https://oscarleo.substack.com), published so others can check and
reuse them.

## Topics

Each topic is a folder with its own README that explains sources, methods and
caveats.

| topic | what |
|---|---|
| [topics/cbi](topics/cbi) | Citizenship and residence by investment in the Eastern Caribbean, Malta, Greece and Turkey: every number with its source, page, quote and status (actual, estimate, budget…), plus programme terms and a timeline |

## Other files

- `china_solar_makers_quarterly-revenue-and-profit.csv`: quarterly revenue and
  profit of Chinese solar manufacturers, used in an earlier chart.
